How it works

  1. Gate check — one scan proves the range non-decreasing. Sorted input exits in O(n).
  2. Spillway check — one scan proves it non-increasing; reverse in place.
  3. Gate pick — median of 5 evenly spaced probes (median-of-3 when small).
  4. Three-lane split — Dutch flag sends each element to <pivot, =pivot or >pivot. The equal lane is final, so duplicates never recurse.
  5. Settle — lanes under 24 elements finish with insertion sort.
  6. Drift — loop on the smaller lane, push the larger, so the explicit stack stays O(log n) whatever the pivots do.

Known primitives, new composition: 3-way quicksort + stratified median sampling + monotone absorption + larger-side iteration. No asymptotic novelty claimed; worst case stays O(n²) like any sampling quicksort.
